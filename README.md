# Evans GSM World - Inventory & Sales Management System

A professional inventory management, POS sales, customer debt tracking, expenses, and financial reporting web application built for Evans GSM World.

## 🚀 Single HTML File Architecture
This application is self-contained entirely within a single **`index.html`** file, powered by Tailwind CSS, modern JavaScript, and local persistence. No server or complex build tools are required!

---

## 📦 Deploying to Vercel (Under 1 Minute)

1. **Create a GitHub Repository**:
   - Create a new public or private repository on GitHub (e.g., `evans-gsm-world`).
   - Upload or push these files to your repository:
     - `index.html` (the core standalone application)
     - `vercel.json` (Vercel deployment configuration)
     - `README.md` (this guide)

2. **Deploy on Vercel**:
   - Go to [Vercel Dashboard](https://vercel.com).
   - Click **Add New...** -> **Project**.
   - Import your GitHub repository (`evans-gsm-world`).
   - Leave build settings as default (Framework Preset: **Other**, Build Command: *leave empty*, Output Directory: `./`).
   - Click **Deploy**!

Your live app will be generated instantly with a secure HTTPS URL.

## 🛠 Features Included
- **Clean White UI**: Minimalist, professional white interface with smooth login loading screen & rolling spinner.
- **POS & Sales**: Fast checkout with cash, transfer, POS terminal, and customer credit/debt support.
- **Inventory & Stock Management**: Stock valuation, low-stock warnings, and purchase logs.
- **Customer Debt Ledger**: Track credit balances and record repayment receipts.
- **Financial Reports**: Gross profit calculation, expense tracking, and printable reports.
- **Data Reset & Backup**: Reset data or backup/restore JSON files anytime.
